# Offline legacy JSX capture

These files reproduce the **source-layout reference**, not a live dashboard. The legacy repository was read but never edited. The captured routes come from `../manifest.json`; `loaders-main.ts` imports the old JSX pages. `loaders-config.ts` isolates `TchedRouterConfigEl` for one bounded attempt. Build both separately because importing the config component into the combined bundle causes an old circular module initialization error.

The browser was an isolated `agent-browser` session (`od84-legacy-*`) launched with `--allowed-domains 127.0.0.1`. `index.html` mocks `fetch`, `WebSocket`, and `EventSource`; no identity, provider, control-plane service, or external network was used. The Vite config has **no proxy**. The config-only build additionally aliases `config-client` to `config-client-offline.ts`, which rejects both reads and writes. No backend result or successful action is fabricated. Its old component still cannot initialize because the legacy registry imports the component before its binding is initialized; `screenshots/legacy/tched-router-config.png` records only that failure. Do not treat it as a visual extraction.

The main screenshots are the original page JSX under legacy Tailwind styles with offline/empty/error states. The four Coming Soon items have no JSX source and are labeled placeholders. Remote Google Fonts were blocked by the browser allowlist; local fallback fonts appear. `screenshots/legacy/coverage.json` records every item, screenshot path, and capture state. The `offline-empty` state means the source page rendered without a connected backend; `error` means the original page rendered an unavailable-service error. It does not mean a populated layout was reproduced.

To reconstruct the local preview, copy these source files into `/tmp/od84-legacy-capture`, symlink only that temporary project's `node_modules` to the legacy repository's installed dependencies, use `loaders-main.ts` as `loaders.ts`, and run Vite build/preview with `vite.config.main.ts` on port 4177. The config-only attempt uses `loaders-config.ts` and `vite.config.config.ts` on port 4179; `capture-config.sh` records its unavailable state after `capture-styled.sh` records the other 45. Set `AGENT_BROWSER_SESSION` to a new named, allowlisted session before either script. Open only `http://127.0.0.1:<port>/?id=<manifest-id>` in a fresh allowlisted browser session. Build outputs, dependencies, browser profile, logs, and credentials are intentionally excluded from this archive.

This harness loads additional transitive, unchanged legacy source modules from `src/components`, `src/stores`, `src/lib`, `src/grpc`, and `src/json-render`; their exact historical revision is recorded in `../manifest.json`. The page source archive and screenshots are the durable visual/content reference.
